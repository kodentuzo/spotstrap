Items that don't match are hidden; a `menu-empty` part says so when nothing matches. It fires
`spotstrap:change`.

## Keyboard (spotstrap/js)

| Key | Does |
| --- | --- |
| Typing | Filters the list |
| ↓ ↑ | Moves between matches |
| Enter | Picks the highlighted match |
| Escape | Closes the list |

It styles the same states as [Listbox](/components/listbox).
