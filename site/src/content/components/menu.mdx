Without a script, `popover` and `commandfor` open it and its items are buttons. With
`@kodentuzo/spotstrap/js`, `init()` adds arrow keys, typeahead and focus handling, and fires
`spotstrap:select` with `{ value }`.

## Classes

| Class | What |
| --- | --- |
| `menu` | The list panel. |
| `menu-item` | A 44px row. `menu-item-destructive` for a destructive action. |
| `menu-label`, `menu-separator` | A group heading and a divider. |
| `menu-compact` | 36px rows, on the `menu`. |

## Keyboard (@kodentuzo/spotstrap/js)

| Key | Does |
| --- | --- |
| Enter, Space, ↓ on the button | Opens the menu |
| ↓ ↑ | Moves between items |
| Enter | Chooses the item |
| Escape | Closes the menu and returns to the button |
| A letter | Jumps to the next item starting with it |

## States it styles

| State | Attributes |
| --- | --- |
| Highlighted | `[data-highlighted]` (Zag, Radix, reka-ui, bits-ui), `[data-focus]`, `[data-active]` (Headless UI), `[data-focused]` (react-aria), `:focus-visible` |
| Disabled | `[data-disabled]`, `[aria-disabled="true"]`, `:disabled` |
