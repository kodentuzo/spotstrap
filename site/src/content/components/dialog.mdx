Open it with a button that has `commandfor` and `command="show-modal"`: no JavaScript needed.
On a phone, or with the preview set to **Phone**, it opens as a sheet.

<Example name="dialog/confirm" title="A confirmation dialog" minHeight={460} />

## Classes

| Class | What |
| --- | --- |
| `dialog` | The panel. Narrower than 40rem, it's a sheet at the bottom. |
| `dialog-title`, `dialog-description` | Its heading and text. |
| `dialog-actions` | Its buttons. On narrow screens they stack full width; put Cancel first and it ends up at the bottom. |

## States it styles

| State | Plain HTML | Headless libraries |
| --- | --- | --- |
| Open | `[open]` | Mounted content is shown; `[data-state="open"]` |
| Closing | — | `[data-state="closed"]`, `[data-closed]`, `[data-exiting]` fade out |

Dialogs fade and scale in, sheets slide up. With reduced motion, both only fade.
