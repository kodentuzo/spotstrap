## Classes

| Class | What |
| --- | --- |
| `popover` | The panel. On a native `[popover]` it's anchored to its button. |

| State | Plain HTML | Headless libraries |
| --- | --- | --- |
| Open | `:popover-open` | Mounted content is shown |
| Closing | — | `[data-state="closed"]`, `[data-closed]`, `[data-exiting]` fade out |
